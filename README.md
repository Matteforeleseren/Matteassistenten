# Matteassistenten

En samling notater, oppgaver og ressurser i matematikk – delt med elever og studenter.

🌐 **Nettside:** [https://matteforeleseren.github.io/Matteassistenten/](https://matteforeleseren.github.io/Matteassistenten/)

---

## Innhold

Nettsiden er en portal med egne sider for hver kategori:

| Kategori | Fil | Beskrivelse |
|---|---|---|
| ENT3R | `ent3r.html` | Matematikkhjelp for elever |
| Matematikk for ingeniører | `ingenior.html` | Forelesningsnotater og oppgaver |
| Matematikk for realfagsstudenter | `realfag.html` | Notater og ressurser |
| Matematikk for lærerstudenter | `laerer.html` | Fagdidaktikk og matematikk |
| Handout-prosjekt (10. klasse) | `handout10.html` | Prosjektmateriell for 10. trinn |
| Handout-prosjekt (VGS) | `handoutvgs.html` | Prosjektmateriell for videregående |
| Min CV | `cv.html` | Erfaring og bakgrunn |
