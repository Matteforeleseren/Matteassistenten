# Matteforeleseren

🌐 **Nettside:** [matteforeleseren.github.io/Matteforeleseren](https://matteforeleseren.github.io/Matteforeleseren/)

---

## Om prosjektet

Matteforeleseren er en samling matematikkressurser jeg har utviklet gjennom mange år som foreleser og forfatter. Her finner du forelesningsnotater, oppgaver, veiledningshefter og prosjektmateriell – organisert etter kategori.

Målet er å gjøre matematikk tilgjengelig og forståelig for flere, og å gi elever, studenter og lærere et sted å finne gode ressurser.
